# RemoteHub Desktop 0.1.0-beta.9

本次预发布修复多 SSH 会话输出时的卡顿，并加强连接、文件和桌面进程的安全保护。

## 本次更新

- SSH 输出按会话分发并合并小片段；后台终端错峰处理，切回前台立即恢复，减少多开时的重复处理。
- 终端消费不及时会暂停读取并随后恢复，控制输出积压；保留分段 UTF-8 字符和关闭前的最后输出。
- 停止后台标签的光标闪烁和 Codex 状态定时查询；修复连接取消后的残留回调与状态覆盖。
- 加强页面导航、窗口、权限和 IPC 来源检查；限制本地 Codex 命令解析，避免从不可信工作目录加载命令。
- 导入连接改变目标或认证设置时不再沿用已有凭据；SFTP 文本编辑按实际读取量限制文件大小。
- CSV 导出默认防护电子表格公式，另提供保留原始内容的导出选项。
- 升级 Electron 至 44.4.5，更新相关依赖并适配原生模块与剪贴板接口。
- 修复 Codex 剩余额度进度条配色。

## 验证

- 本地通过 231 项测试、类型检查、代码检查和生产构建。
- 通过 40 个本机回环 SSH 会话压测及实际终端渲染检查，约 10 MB 输出完整；不使用保存的连接或凭据。
- 各平台安装包还须通过发布流水线中的打包后离线启动检查，才会发布。

## 选择下载文件

- Windows 10/11 x64：`win-x64-setup.exe` 为安装版，`win-x64-portable.exe` 为免安装版。
- macOS Intel：`mac-x64.dmg`；Apple Silicon：`mac-arm64.dmg`。
- Linux x64：`linux-x86_64.AppImage`。
- 安装包自带运行时，无需另装 Node.js、npm 或 pnpm。
